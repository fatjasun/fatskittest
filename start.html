HEN 14.02 — ps4-hen rebuild (hen-1402.bin) The 14.02 build: entry gate 4.74–14.02 and a 14.02 kernel branch table. Pre-flight checks both before the thread starts, then it installs HEN and starts FTP on 2121. BinLoader receiver (binloader.bin) Firmware-independent payload receiver. Listens on TCP 9020, takes raw (E9) and ELF64 payloads, and re-listens after each one. Send hen.bin or hello.elf with netcat from the PC. Jailbreak only — no payload uid 0 and the standalone Debug Settings patch (read back after the write). Stops cleanly before the payload loader, so it cannot crash. Bundled GoldHEN (goldhen.bin) Installs GoldHEN's own 14.02 kernel payload (kpayload.elf), then starts the loader at 0x926200000. Refuses if the payload is not the 14.02 build or if 0x100000 is taken. Bundled HEN (hen.bin) Pack payload, no host byte patches. Original payload (payload.bin) Pack payload, no host byte patches. Debug payload (debug.bin) Pack payload, no host byte patches. Custom GoldHEN (goldhen-custom.bin) Your build, fixed base 0x926200000. Applies the verified 14.02 kernel patch set first and refuses to launch if it does not verify. Custom HEN (hen-custom.bin) Your build, no fixed base (link address unknown).
